# Contributing

1. Pull the latest default branch and create a focused branch, for example `feature/US-03-recipe-details`.
2. Make one cohesive change and add tests for its acceptance criteria.
3. Run `python -m pytest` locally.
4. Open a pull request with the story ID, behavior changed, tests run, and any open questions.
5. Ask a teammate to review before merging.

Use sample or synthetic recipe data only. Do not commit secrets, credentials, or personal information.
